## Building
The assembly code is written in [KickAssembler](https://www.theweb.dk/KickAssembler/Main.html) syntax, so it must be built as such. I recommend using the [Kick Assembler 8-Bit Retro Studio](https://open-vsx.org/extension/paulhocker/kick-assembler-vscode-ext) VSCode Extension, as it streamlines the process quite a bit.
